Decision sequence of an activated offender agent

Step through the sequence, or click any block.

Simplified flowchart of the decision sequence executed by each activated offender agent at a single simulation time step. Yellow rectangles denote actions; green diamonds denote points at which the algorithm branches on a condition. The right-hand column lists the theoretical literature motivating each step. The sequence is repeated for every agent at every time step until the stopping condition is met (in the manuscript, until all criminal opportunities are exploited). In the step-through, branches are drawn at random for illustration; use ← / → keys to step.

Key equations

Partner utility (solo option uses ω̃i,i=1)
Ui,j(t) = βtrust ω̃i,j(t) + βskill s̃jψ(t)
Choice probability (softmax)
pi,j(t) = exp Ui,j / [exp Ui,i + Σk exp Ui,k]
Success probability
p(success | γ) = max(0.1, ((siψ + sjψ) / Nco)γ)
Nco = number of COs per crime type; sjψ = 0 for solo offences.
Step length (truncated power law)
P(δ) ∝ δ−ν, δ ∈ [δmin, δmax], 1 < ν ≤ 3
